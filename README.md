# AI Predictive Maintenance

Machine Learning models for predicting equipment failures before they occur.

## Overview

This project uses Artificial Intelligence and Machine Learning to predict equipment failures, helping maintenance teams reduce downtime, improve reliability, and optimize maintenance schedules.

## Features

- Equipment failure prediction
- Remaining Useful Life (RUL) estimation
- Predictive maintenance analytics
- Data visualization dashboard
- Machine learning model training

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```
